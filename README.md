# PRIYA DEVELOPERS — ANUGRAHA

Responsive static real-estate website using the supplied Priya Developers logo, ANUGRAHA elevation, parking plan, 2D/3D floor plans, highlights graphic and location QR.

## Files
- index.html
- style.css
- script.js
- assets/

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders in this package to the repository root.
3. Go to Settings → Pages.
4. Select "Deploy from a branch", branch `main`, folder `/ (root)`.
5. Save.

No build process or server is required.

## Important content note
The website uses the current project details supplied in the chat for the main price/location figures. The supplied brochure contains some older/different distance and pricing figures on different pages, so those were not silently substituted into the main website.
